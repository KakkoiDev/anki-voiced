# anki-voiced

Build Japanese Anki decks with natural AI voice, pitch accent, per-kanji furigana, and a proven 3-card pedagogy. One command, one slug, one `.apkg`.

```sh
pip install anki-voiced
python -m unidic download                # one-time, ~500MB (for pitch accent)

anki-voiced init my-deck                 # scaffold decks/my-deck/
# edit decks/my-deck/tier1-vocabulary.csv
anki-voiced validate --deck my-deck
anki-voiced pitch    --deck my-deck      # fill PitchAccent column
anki-voiced audio    --deck my-deck      # Edge TTS -> tier1-audio/*.mp3
anki-voiced create   --deck my-deck      # -> my-deck-complete.apkg
```

## Why

The common Anki Japanese deck tools are either clunky or generic. Typical pain points:

- Furigana over okurigana (`食べる【たべる】` instead of `食【た】べる`)
- Robot-sounding TTS (no particle pauses, misread kanji)
- No pitch accent, or pitch that doesn't align with mora
- "Double card" designs that encourage reading-along during listening

`anki-voiced` ports the proven design from a production deck into a clean Python package:

Its reusable Japanese primitives come from [JP Core](https://github.com/KakkoiDev/jp-core); this repository owns the deck-oriented CLI, schemas, templates, and orchestration.

- **Edge TTS** (`ja-JP-KeitaNeural` / `NanamiNeural`) for natural prosody
- **UniDic-powered pitch accent** coloring (high=green, low=red) on every key word
- **Per-kanji furigana** format (`取【と】り組【く】む`)
- **3-card model**: audio-only listening, text-only reading, cloze vocabulary
- **Register badges** (casual/polite/formal/keigo)
- **300+ tech acronym -> katakana** map
- **Particle pause insertion** (`を` / `が` / `まず`)
- **Kanji override** for Edge TTS misreadings (no CSV surgery needed)
- **SHA256 cache** for TTS audio (rebuilds are instant)
- **Slug-based deck layout** - each deck is self-contained

## Card design

Three cards per note:

1. **Listening** - oversized play button only. No text. Forces working memory.
2. **Reading** - plain Japanese sentence, no audio. Tests reading alone.
3. **Vocabulary** - sentence with the key word blanked (JS). Tests single-vocab recall.

Back of each card shows furigana, translation, register badge, and the key word with colored pitch accent.

Dark mode via Anki's native `.night_mode`.

## CSV schema

Nine columns, case-sensitive:

| Column       | Purpose |
|--------------|---------|
| Sentence     | Japanese sentence (display form with per-kanji furigana) |
| Translation  | English translation |
| Cloze        | Key vocabulary word |
| Pronunciation| Dual-purpose: card display (via ruby HTML) and TTS input |
| Note         | Category/tag shown as a chip on cards |
| Register     | casual / polite / formal / keigo |
| KeyMeaning   | English gloss of Cloze |
| PitchAccent  | Auto-generated colored ruby HTML (run `anki-voiced pitch`) |
| Audio        | Auto-generated `[sound:tierN_NNN.mp3]` reference |

Example:

```csv
Sentence,Translation,Cloze,Pronunciation,Note,Register,KeyMeaning,PitchAccent,Audio
会議【かいぎ】は10時【じ】です。,The meeting is at 10.,会議,会議【かいぎ】は10時【じ】です。,Business - Meetings,polite,meeting,,
```

## Deck layout

```
decks/
  my-deck/
    deck.toml                 # slug, model_id, tier names and sizes
    tier1-vocabulary.csv      # 9-column schema
    tier1-audio/              # generated by `anki-voiced audio`
    tier2-vocabulary.csv      # more tiers as needed
    tier2-audio/
```

Minimal `deck.toml`:

```toml
[deck]
slug = "my-deck"
name = "My Japanese Deck"
model_id = 1607392323
deck_base_id = 2059400110

[tiers]
count = 1

[tiers.names]
1 = "Tier 1 - Basics"

[tiers.sizes]
1 = 100
```

## Commands

| Command | Purpose |
|---------|---------|
| `anki-voiced init <slug>` | Scaffold `decks/<slug>/` with deck.toml and a starter CSV |
| `anki-voiced decks` | List configured decks |
| `anki-voiced validate --deck <slug> [--tier N] [--check-audio]` | Validate CSV (and audio) |
| `anki-voiced pitch --deck <slug> [--tier N]` | Generate PitchAccent HTML (UniDic) |
| `anki-voiced audio --deck <slug> [--tier N] [--female] [--force]` | Generate Edge TTS MP3s |
| `anki-voiced create --deck <slug> [--tier N]` | Build `.apkg` |
| `anki-voiced voices` | Show Edge TTS Japanese voices |
| `anki-voiced join <apkg>... -o out.apkg -n Name` | Combine built decks |
| `anki-voiced create path.csv -o out.apkg` | One-shot build from a single CSV |

All commands support `--json` and `--quiet` for scripting.

## Claude Code integration

This repo ships a Claude skill and agent:

```sh
# Skill: provides CSV/furigana/TTS rules
ln -sf "$(pwd)/skills/anki-voiced" ~/.claude/skills/anki-voiced

# Agent: drives the pipeline from vocabulary wishes
# Loaded automatically when .claude/agents/anki-voiced.md is in the project
```

Example prompt: *"add 10 daily-life phrases about shopping to decks/housewife"*. The agent appends rows, runs validate, pitch, audio, create, and reports.

## TTS quality tips

- Particle `は` is auto-replaced with `わ` (Edge TTS otherwise reads it as "ha")
- `を` and context-marker `が` get a `、` for natural pauses
- Introductory adverbs (`まず`, `次に`, `実は`, ...) get a trailing `、`
- English acronyms and tech terms map to katakana (`API -> エーピーアイ`, `EC2 -> イーシーツー`)
- Percent signs and `vN` version strings are normalized

### Fixing a kanji Edge TTS misreads

Don't edit the CSV. Add the kanji to `TTS_KANJI_OVERRIDES` in `src/anki_voiced/preprocessing/acronyms.py`, then:

```sh
anki-voiced audio --deck <slug> --force
```
